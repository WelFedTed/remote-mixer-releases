# Remote Mixer

Control the Windows audio mixer from your phone: one fader per app (Spotify, Discord, games),
with mute, solo, and master volume. Browser tabs (Chrome, Edge, Firefox) and the people in a
Discord voice chat get their own faders too.

This repository has the **downloads** only. Get the latest version from
[Releases](https://github.com/WelFedTed/remote-mixer-releases/releases/latest):

- `remote-mixer.exe` — the Windows app (runs in the system tray). Installed copies update themselves.
- `remote-mixer-extension.zip` — browser extension for Chrome, Edge, Brave (load unpacked in developer mode).
- `remote-mixer-firefox.xpi` — browser extension for Firefox and its forks.

The `ad/` folder is the banner page that the app shows in an isolated frame.
